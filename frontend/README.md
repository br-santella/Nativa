# frontend — frente 5

React + Vite + TypeScript, MapLibre GL, Recharts, TanStack Query e Zustand.

Telas: formulário da fazenda, editor do plano de safra (linha do tempo jul → jun), comparação das 4
estratégias com semáforo e decomposição da nota, calendário de vulnerabilidade, slider de cenário.

Para iniciar: `npm create vite@latest . -- --template react-ts` dentro desta pasta.
Tipos da API: gerados do OpenAPI com `openapi-typescript` (não editar à mão).
